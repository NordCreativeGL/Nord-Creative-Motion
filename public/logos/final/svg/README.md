# Nord Creative — SVG assets

Six clean SVG files — wordmark (two variants) and icon, in both white and black. Text is converted to outlines (paths) so the files are fully self-contained and render identically anywhere — no font installation required.

## White (for dark backgrounds)

| File | Contents |
|---|---|
| `nord-creative-wordmark-needle-white.svg` | "NORD CREATIVE" wordmark, with the compass-needle diamond replacing the I in CREATIVE |
| `nord-creative-wordmark-plain-white.svg` | "NORD CREATIVE" wordmark, with a plain I (no needle) |
| `nord-creative-icon-white.svg` | The split-ring + compass-needle icon (L · wide needle variant) |

## Black (for light backgrounds)

| File | Contents |
|---|---|
| `nord-creative-wordmark-needle-black.svg` | Same wordmark with needle, in black |
| `nord-creative-wordmark-plain-black.svg` | Same wordmark with plain I, in black |
| `nord-creative-icon-black.svg` | Same icon, in black |

## Specs

- **Wordmarks** — 200px font-size reference, viewBox is W × 200
- **Icon** — viewBox 0 0 100 100 (square)
- **Background** — transparent (no rect fill)
- **Stroke** — only used on the icon ring (width 3.5 in viewBox units)
- **Font** — text is outlined from Montserrat ExtraLight (weight 200). No font dependency.
- **Needle position** — geometrically centred between T and V (equal gaps on both sides)
